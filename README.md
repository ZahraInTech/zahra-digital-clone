# 🌊 Zahra Mumtaz — AI Digital Clone

An interactive Hybrid RAG (BM25 + Dense Vector Search via Reciprocal Rank Fusion) system powered by Groq LLM inference. Indexes my academic research (Emora, TrashSense), software development stack, study methodology, and culinary baking background.

## 🚀 System Architecture
- **LLM Inference Engine:** Groq API (`qwen-2.5-32b`)
- **Hybrid Retrieval:** BM25 Lexical + Sentence Transformers Dense Vector Search combined with Reciprocal Rank Fusion (RRF)
- **Frontend Framework:** Streamlit (Coastal Ocean Aesthetic UI)
- **Deployment Platform:** Streamlit Community Cloud
