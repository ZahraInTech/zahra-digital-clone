## IBM Bob 2.0 Hackathon — Project Repo-Tutor (LabLab.ai)
- **Role & Team:** Team Lead for team "Bob's Builders".
- **Project Overview:** Repo-Tutor is an AI-powered developer onboarding copilot built to streamline code understanding and eliminate friction for engineers navigating complex codebases.
- **Technical Architecture:** Developed using IBM Bob 2.0 tools and LangGraph multi-agent orchestration to index multi-directory GitHub repositories, parse abstract syntax tree (AST) structures, and construct dependency representations.
- **Key Features:** System automatically answers architectural and code-level developer queries while providing precise inline source code references and dependency guidance.
- **Team Leadership:** Directed system architecture design, multi-agent routing logic, repository setup, and presentation preparation.
