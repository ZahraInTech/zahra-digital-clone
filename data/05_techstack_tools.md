# Developer Toolchain, Libraries, and Technology Index

## Programming & Scripting Languages
- **Python:** Primary language for Machine Learning, Deep Learning pipelines, PyTorch model training, data preprocessing, and script automation.
- **C++:** Used in foundational Computer Science coursework for core algorithms, data structures, and memory management concepts.
- **SQL:** Relational database querying, multi-table joins, subqueries, aggregation, and relational schema design.
- **Java & XML:** Applied in Mobile Application Development for building native Android application user interfaces and logic.
- **Assembly Language:** Used in low-level Computer Organization & Assembly Language coursework for basic memory indexing and instruction-level programming.
- **HTML/CSS:** Basic web markup and styling.

## Machine Learning, Deep Learning, and AI Tooling
- **PyTorch:** Neural network architectures, autograd gradient tracking, custom dataset loaders, training loop optimization, and GPU acceleration.
- **Transformers & Computer Vision:** Hugging Face `transformers` library (BERT, RoBERTa), `torchvision` (ResNet-50, MobileNetV2), OpenCV for image preprocessing, and YOLO object detection.
- **Explainable AI (XAI):** Grad-CAM for CNN activation heatmaps and token-level attribution maps for text sentiment evaluation.
- **LLM & Agent Frameworks:** LM Studio for running local quantized GGUF models (e.g., Llama, Qwen, Gemma), LangGraph for stateful multi-agent flow graphs, OpenAI API Python SDK, and Gradio for rapid web UI prototyping.

## Data & Database Tools
- **Relational Databases:** SQL database querying, normalization, and relational schema design.
- **Data Utilities:** Microsoft Excel for tabular data organization and basic analysis.

## Cloud & Infrastructure Basics
- **Amazon Web Services (AWS):** Introductory experience with AWS DynamoDB NoSQL table configuration (partition/sort key mechanics) and S3 storage management.

## Development Environment & Tooling
- **IDE & Editors:** Visual Studio Code (Python, C++ extensions) and Overleaf LaTeX editor for academic paper writing.
- **Cloud & Runtimes:** Google Colab (GPU-accelerated runtimes) and Linux Ubuntu CLI environment.
- **Version Control:** Git & GitHub (ZahraInTech) for code repository management and version history tracking.
